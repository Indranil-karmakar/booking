# Havenstead Cleaning

Frontend prototype for a professional house and carpet cleaning company. One unified booking flow, instant estimates, mock Square checkout.

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Demo notes

- No backend, payments, or email are real.
- Unserviced ZIP codes for the availability demo: `00000`, `11111`, `99999`, `00001`, `55555`.
- Payment success: `4242 4242 4242 4242`. Failure: end the card number with `0002`.
